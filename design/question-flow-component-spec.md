# 问答流程页设计参考

来源：用户在 2026-06-02 对话中提供的问答流程页组件拆解图。

本地未能直接读取到对话图片的原始二进制文件，因此先将设计要点沉淀在此文件中；如需保存原图，请将图片拖入 `design/` 目录后命名为 `question-flow-component-spec.png`。

## 关键规范

- 顶部导航栏：白底卡片，圆角约 12px，含返回、`3 / 6` 进度文本、跳过按钮。
- 进度条：6 段胶囊条，已完成和当前为品牌绿，未完成为浅灰。
- 标题区：问题标题居中，约 24px / Semibold；辅助说明约 16px / Regular。
- 选项卡：单题单屏，大卡片纵向排列，圆角约 20px，阴影轻，内边距约 24px。
- 选项主题：重口/热食/正餐等使用浅红背景，清淡/凉食/小吃等使用浅绿背景。
- 交互：按下态轻微缩放，边框变主题色，右上角出现选中标记；当前流程点击后直接进入下一题。
- 色彩：品牌绿 `#22C55E`，重口红 `#EF4444`，主文字 `#111827`，辅助文字 `#6B7280`，背景白色。
