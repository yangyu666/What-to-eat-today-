# 《今天吃什么》设计交接说明

本目录用于沉淀《今天吃什么》小程序的产品原型、视觉约定和跨 Codex 窗口开发上下文。

## 1. 设计资料

- 对应 PRD：`今天吃什么 PRD v1.3`
- 原型图目标路径：`design/prototype-v1.3.png`
- 当前页面范围：
  - 首页
  - 问题流程页
  - 推荐结果页
  - 历史记录页

> 注意：如果 `design/prototype-v1.3.png` 暂不存在，说明当前聊天上传的图片尚未导出到本地文件系统。请将原型图保存到该路径后继续开发。

## 2. 原型页面说明

### 首页

- 顶部展示位置，例如 `北京市 · 海淀区`。
- 右上角展示天气卡片。
- 主视觉为问候语和产品标题：`今天吃什么？`。
- 核心行动按钮：
  - `帮我决定`
  - `我有要求`
- 下方展示最近推荐卡片列表。
- 底部 Tab：
  - 首页
  - 历史
  - 我的

### 问题流程页

- 单题单屏。
- 顶部包含返回、进度，例如 `3 / 6`，以及 `跳过`。
- 使用绿色进度条展示问答进度。
- 当前原型示例问题：`今天想吃重口还是清淡？`
- 选项使用大卡片：
  - 重口味
  - 清淡
- 选项卡片可包含食物图片、主标题和辅助描述。

### 推荐结果页

- 顶部标题：`为你推荐`。
- 顶部右侧提供刷新/重新推荐入口。
- 主卡展示餐厅图片、店名、距离、人均、评分。
- 右侧突出展示匹配度，例如 `86% 匹配度`。
- 推荐理由使用绿色勾选列表。
- 底部按钮：
  - `就吃这家`
  - `换一家`

### 历史记录页

- 顶部标题：`历史记录`。
- 筛选项：
  - 全部
  - 本周
  - 本月
  - 自定义
- 列表项展示餐厅图片、店名、时间、匹配度和推荐理由摘要。
- 底部 Tab 保持和首页一致。

## 3. 视觉与交互约定

- 产品形态：微信小程序，移动端优先。
- 主色：绿色，接近 `#18C653` / `#20C85A`。
- 背景：白色或非常浅的灰白色。
- 内容承载：卡片式布局、轻阴影、圆角。
- 按钮：主按钮使用绿色填充，次按钮使用白底描边或浅灰边框。
- 图标：优先使用小程序可用图标或项目已有图标方案。
- 文案风格：直接、轻松、帮用户快速做决定，避免复杂解释。
- 页面目标：帮助用户在 30 到 60 秒内结束“吃什么”的选择困难。

## 4. 开发约定

- 先实现前端闭环，再接真实服务。
- MVP 初期优先使用 mock 数据。
- 暂不接入高德 POI。
- 暂不接入 DeepSeek AI。
- 推荐算法先使用本地规则引擎。
- 页面还原优先级：
  1. 首页
  2. 问题流程页
  3. 推荐结果页
  4. 历史记录页
- 实现时不要重构无关代码。
- 保持已有数据结构和项目风格。
