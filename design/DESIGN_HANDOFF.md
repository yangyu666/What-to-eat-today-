# 《今天吃什么》设计交接说明

本文件用于沉淀《今天吃什么》微信小程序的产品流程、页面状态和上线前约定。

## 1. 当前页面范围

- 首页
- 动态问答页
- 推荐结果页
- 历史记录页

参考原型：`design/prototype-v1.3.png`

## 2. 当前真实流程

1. 首页点击 `帮我决定`。
2. 进入动态问答页，系统从题库中选择一组问题。
3. 用户可选择选项，也可跳过非必答问题。
4. 提交问答结果后进入结果页。
5. 结果页优先读取高德 POI 候选；定位失败、高德 API 失败或高德无结果时降级到云端/本地推荐。
6. 用户可有限次数点击 `换一家`，也可点击 `就吃这家` 采纳结果。
7. 推荐展示、跳过、采纳会写入历史记录；云函数失败时保留本地历史。
8. 历史记录页可查看全部、已采纳、已跳过记录；为空时展示空状态。

## 3. 首页

- 顶部展示定位状态，定位失败时允许用户再次点击获取位置。
- 主按钮只有 `帮我决定`，不再展示或描述 `我有要求`。
- 首页保留历史入口和最近推荐区域。
- 最近推荐图片本轮保留原远程图片与原 fallback 策略。

## 4. 动态问答页

- 单题单屏，顶部包含返回、进度和跳过入口。
- 支持用户跳过部分问题；跳过会写入空选项答案，不阻断推荐。
- 题库图片当前保留原远程图片配置；本地化图片资源处理暂缓。

## 5. 推荐结果页

- 展示餐厅/候选名称、推荐菜、匹配度、距离、人均、评分、来源和推荐理由。
- 高德 POI 有图片时优先使用高德返回图片；图片失败或无图时展示页面占位。
- `换一家` 有次数上限，连续切换后提示锁定当前结果。
- 没有推荐候选时展示空状态，不进入不可操作的结果卡片。
- 推荐链路不新增 AI，不改变现有推荐算法大逻辑。

## 6. 历史记录页

- 筛选项：全部、已采纳、已跳过。
- 历史为空时展示对应空文案。
- 云端读取失败时降级读取本地历史。
- 历史图片 fallback 本轮保留原远程图片策略。

## 7. 异常处理约定

- 定位失败：高德推荐跳过，进入云端/本地推荐降级；首页定位状态可重试。
- 高德 API 失败：服务层捕获错误并降级。
- 高德无结果：返回空候选，继续走后续推荐来源。
- 云函数失败：推荐云函数失败时降级本地；历史保存云函数失败时保留本地记录。
- 用户跳过问题：跳过答案保留为 `null`，推荐映射按已答项计算。
- 图片加载失败：本轮暂不做本地资源替换，结果页失败时回到无图占位。
- 连续换一家：限制次数，达到上限后锁定当前推荐。
- 没有推荐候选：结果页展示空状态。
- 历史记录为空：历史页展示空状态。

## 8. 图片资源约定

- 按当前最新要求，本轮暂不替换 `images.unsplash.com`。
- `questionBank`、首页最近推荐和历史记录 fallback 先保留原图片来源。
- 图片本地化仍是上线前风险，后续需要单独处理资源包大小、版权和弱网加载策略。

## 9. 开发约定

- 不重构无关代码。
- 不新增 AI。
- 不处理 JS/TS 双轨大重构；涉及页面 `.ts` 时同步对应 `.js`。
- 不提交 `.tmp/` 测试构建产物。
